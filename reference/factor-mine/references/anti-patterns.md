# 因子挖掘反模式（本地版）

| 反模式 | 为什么错 | 修复 |
|---|---|---|
| 同时改 N 个东西 | 指标变了无法归因，不可复用 | 拆成 N 次实验，每次一个 op_type |
| 没写 ITER_NOTE 就跑 | 没有假设就没有研究 | 见 `iter-note.md` |
| `hypothesis: "试试看"` | 不是假设，是赌博 | 写出经济/统计因果 |
| `expected: "提升"` | 无法事后判断对错 | 给具体指标区间 |
| 给已有因子换皮再入库 | 共线性，无新信息 | 相关性门控，见 `correlation-gate.md` |
| 全样本拟合参数 / 全段 z-score | 未来函数 | 只用滚动历史窗口的统计量 |
| 用全时段调参选"最优窗口"再报全时段指标 | 隐性过拟合，OOS 必衰减 | IS 段选参（2024~2025），OOS 段（2026+）验证，见 `is-oos-protocol.md` |
| 用 OOS 段结果回头设计假设 / 调参让 OOS 变好 | 测试集污染：OOS 每参与一次决策就失效一分，最终又退回全样本过拟合 | OOS 只做一次性验证门；fail 就回滚回 IS 重新挖；同谱系 OOS_REJECT ≥3 次冻结该方向 |
| 绕开框架双门禁（手写缓存绕过 check_cutoff、注释掉静态扫描） | 未来函数防线失效，IC 虚高 | 扫描+回放是硬门禁，过不了就修实现 |
| 把指标缺失（null）当 0 处理 | null 是"不可认证"，不是"零"；框架故意不零填充 | 按 SKILL.md 门槛，null 一律视为 FAIL |
| 拿 all_costs 的 null/known_segment 说"扣资金费后也赚钱" | 场景账本不完整时该段指标是 null 而非零；覆盖日程是数据派生的，强度有限 | 决策口径固定 trading_net；all_costs 已认证时作参考门，未认证（null）时不作任何方向解读 |
| 忽略 universe 自创可交易集合 | coverage 失真，universe 扩张伪装成信号改善 | `SETTING["universe"]="historical_top50"`（唯一合法值），诊断时看报告覆盖率块 |
| 调低 fee/slippage 让 net 转正 | 自欺欺人 | fee=0.0005、slippage=0.001 固定，net 不行就压 turnover 或增强信号 |
| warmup_bars 不够 | 前期全 NaN，截面规模不足，分组失真 | warmup ≥ 最长滚动窗口 + 余量 |
| 50 行复杂工程换 0.002 RankIC | 复杂度成本 / 可解释性差 / 易过拟合 | 简单可解释优先 |
| 报告只看 NAV 就下结论 | 漏掉换手成本、分组不单调、coverage 失真 | 逐块诊断：NAV / 分组单调性 / IC 衰减 / 换手 / 覆盖率 |
| 逐轮"删成分 → 指标变好"收敛到单字段裸信号 | 每步合法、累计是全样本选择过拟合；被删成分可能有 OOS 价值 | 删减决策用 IS 段复核；保留多成分版本做对照 |
| 以"迭代"名义偷换因子身份（字段/category 变了还沿用原名） | 名字与经济内容脱节，日志归因混乱，换皮因子混入 | 身份漂移即改名 + 按 add_factor 重建档、重跑相关性门控 |
| 单字段 beta 信号当终点且无机制论证 | 大概率与库内同字段因子高相关，无信息增量；因子库退化成 beta 堆叠 | ITER_NOTE 论证机制与增量，或改走 compose_factor 组合正交字段 |
| 用 unsubmit 旧因子里的 mark/index/OI/基差字段写新因子 | 本地 H5 没有这些字段，loader 直接缺键报错 | 只用 signal-contract.md 列出的可得字段 |

## 危险信号清单（看到立刻停，先查未来函数）

- |RankIC| > 0.15
- trading_net 年化 > 100% 且 maxdd < 10%
- trading_net sharpe > 5
- IS / OOS 指标量级一致且都异常好（真实因子 OOS 通常比 IS 衰减 30~70%）
- 分组收益完美单调且 top 组收益离谱

## 本地特有的坑

- **样本期短**：数据 2023-07-05 起，IS 只有 2024~2025 两年。两年窗口里"每年都为正"
  的年度鲁棒性检验力度弱，结论保持保守；不要用 2023H2 凑样本（那是 warmup 区）
- **universe 构成变化**：CMC top50 是 point-in-time 成员，2024→2026 成员与市值
  结构在变；IC 改善可能只是宇宙变化的假象——用报告覆盖率块与固定子区间复核
- **funding 成本不入决策**：trading_net 只含 fee+slippage；真实持仓还有资金费。
  空头占比高或持有高 funding 币的因子，实盘净收益会低于 trading_net 口径
- **funding 字段质量**：结算覆盖由数据派生时刻表支撑（非官方日程，强度有限），
  费率做信号可以，但别把它当精确的现金流数据用
- **占位 K 线**：`has_placeholder_kline`（零量平价）由框架挡新开仓；因子侧若对
  这类 bar 计算指标（如波动率=0），要自己 mask，别让假平稳污染滚动统计量
- **Genetic_Algorithm 的 test 段**：与本 skill 的 OOS 同为 2026+，已冻结；
  两边的 OOS/test 结果不能互相引用做决策
